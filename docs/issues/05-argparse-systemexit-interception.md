# CLI catches SystemExit to rewrite argparse's exit code; override ArgumentParser.error instead

## Problem

`main()` catches `SystemExit` from `parse_args()`, checks for exit code 2, prints a hint and exits with 1. Any other exit is re-raised, and comments explained which exits were which ("Re-raise other SystemExits (like --help…)"):

https://github.com/michellepace/youtube-to-xml/blob/31a8828f2bcea8290fa8bd67c768b42ce4f27d42/src/youtube_to_xml/cli.py#L156-L166

Inferring "argument error" from a magic exit code (`ARGPARSE_ERROR_CODE = 2`) is a workaround. argparse provides a hook for exactly this case.

These comments were removed in the comment audit (ADR 0001), and this issue tracks the workaround they explained.

## Suggested fix

Subclass `argparse.ArgumentParser` and override `error(message)`: print usage and the message, add `Try: youtube-to-xml --help`, then `sys.exit(1)`. `main()` then needs no `try/except SystemExit` and no `ARGPARSE_ERROR_CODE`. `test_cli_shows_argparse_error_for_no_arguments` already covers the behaviour.
